# 🎬 Movie Sales Analysis Dashboard | Power BI

## 📌 Project Overview
This project analyzes IMDb movie data using Microsoft Power BI to understand movie ratings, genres, revenue, and overall movie performance.

## 🎯 Objectives
- Analyze movie release trends over time.
- Explore genre-wise ratings and revenue.
- Identify top-performing movies and directors.
- Understand the relationship between ratings, votes, runtime, and revenue.
- Create interactive dashboards for data-driven insights.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- IMDb Dataset

## 📊 Key Analysis Areas
1. Movie Overview & Time Trends
2. Genre & Rating Analysis
3. Top Performers & Box Office Insights
4. Correlation & Advanced Metrics

## 📁 Project File
- `IMBD.pbix` — Power BI dashboard file.

## 🚀 How to Use
1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard and its visualizations.

## 🎓 Project Outcome
This project demonstrates skills in data visualization, data analysis, dashboard development, and business intelligence using Power BI.
